Montar Relatório Padrão (Ultralims)

Fluxo para configurar um modelo a partir do PDF do cliente:

  • Importar PDF — gera HTML rascunho (tabelas ou layout fiel).
  • Edite HTML e CSS no painel esquerdo; veja o preview.
  • Abra Variáveis para trocar datas, CNPJ, valores etc. por {{tokens}}.
  • Exportar HTML → cole no Codex: Gerais → Relatórios e Variáveis → Relatório Padrão.
  • Use Gerar PDF só para conferir o layout localmente.
