Como usar a ferramenta

Você pode montar e ajustar o layout em poucos passos:

  • Carregue o seu HTML e CSS pelos botões do topo.
  • Edite o CSS no painel esquerdo e veja a pré-visualização à direita.
  • Use os botões de Templates para salvar ou restaurar versões.
  • Exporte o CSS quando estiver satisfeito com o resultado.
